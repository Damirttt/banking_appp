# banking_app

План обучения Java — Banking System
Схема приложения
Продолжительность: 11 занятий по 60–90 минут.
Цель курса: разработать банковское консольное приложение на Java, изучить OOP, SOLID, Reflection, создать собственную файловую ORM и научиться работать с внешними API.
Материалы для изучения будут выдаваться походу курса.
Урок 1. Основы Java и классы
• Переменные и типы данных
• Условные операторы (if, switch)
• Циклы (for, while)
• Методы и параметры
• Классы, объекты и конструкторы
• Коллекции (List, ArrayList)
• Работа с консолью (Scanner)

Домашнее задание: самостоятельно реализовать Banking System с хранением данных в памяти (List<User>, List<Account>, List<Transaction>).

Функциональность:
• Регистрация и авторизация пользователей
• Создание счетов в разных валютах
• Пополнение и снятие виртуальных денег
• Обязательный комментарий при снятии
• Просмотр истории транзакций
• Блокировка пользователей администратором
• Повышение пользователей до администраторов

Урок 2. Object-Oriented Programming
• Инкапсуляция
• Абстракция
• Наследование
• Полиморфизм
• Композиция
• Модификаторы доступа
• Enum
Практика: рефакторинг Banking System с применением принципов OOP.

Урок 3. SOLID и архитектура приложения
• Принципы SOLID
• Интерфейсы и абстрактные классы
• Dependency Injection
• Разделение ответственности
• Service Layer и Repository Pattern

Практика: разделение приложения на сервисы, модели и репозитории. Создание InMemoryRepository.
Урок 4. Java Reflection API
Class<?>
• Field, Method, Constructor
• Получение полей и методов класса
• Чтение и изменение приватных полей
• Создание объектов через Reflection
• Работа с наследованием
Практика: создание универсального ObjectInspector и ObjectMapper.

Урок 5. Аннотации и сериализация
• Создание собственных аннотаций
• @Retention и @Target
• Обработка аннотаций через Reflection
• Основы сериализации объектов
• Работа с файлами (Files, Path)
Практика: создание аннотаций @Entity, @Id, @Column и сохранение объектов в файлы.

Урок 6. Десериализация и Generics
• Generics (<T>)
• Создание объектов через Reflection
• Преобразование строк в Java-типы
• Обработка исключений
• Чтение данных из файлов
Практика: реализация универсального механизма восстановления объектов из файлов.

Урок 7. Разработка собственной ORM
• Generic Repository
• Универсальные CRUD-операции
• save(), findById(), findAll(), delete()
• Работа со связями между сущностями
• Интеграция ORM с Banking System
Практика: замена хранения в памяти на собственную файловую ORM.

Урок 8. HTTP API и конвертация валют
• HTTP и REST API
• Java HttpClient
• JSON
• Сериализация и десериализация JSON
• Обработка ошибок внешних сервисов
Практика: реализация конвертации валют между счетами по актуальному курсу через внешний API.

Урок 9. Дополнительная функциональность — часть 1

Урок 10. Дополнительная функциональность — часть 2
Вариант A — AI:
• Анализ транзакций пользователя
• Категоризация расходов
• Генерация рекомендаций по расходам
Вариант B — Мультиязычность:
• Перевод интерфейса на английский, русский и узбекский
• Переключение языка
• Сохранение языковых настроек пользователя

Урок 11. Финализация проекта
• Code Review
• Рефакторинг
• Обработка ошибок
• Тестирование бизнес-логики
• Демонстрация готового приложения
• Разбор архитектурных решений

Итог курса: полноценное консольное банковское приложение на Java с собственной файловой ORM, управлением пользователями и счетами, историей транзакций, конвертацией валют и дополнительной интеграцией с AI или системой локализации.
